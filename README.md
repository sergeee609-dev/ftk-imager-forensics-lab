# FTK Imager Digital Forensics Lab

## Project Overview
This project documents my hands-on exploration of Exterro FTK Imager as part of my digital forensics coursework. The lab focuses on evidence navigation, keyword searching, file exports, hash-list review, and hexadecimal analysis using provided training materials.

## Tools and Technologies
- Exterro FTK Imager
- Windows
- MD5 and SHA-1 hash values
- Hexadecimal and ASCII viewer
- Provided practice evidence files

## Lab Workflow

### 1. Installation and Setup
Installed FTK Imager and familiarized myself with its Evidence Tree and File List interface.

### 2. Loading Evidence
Loaded the provided practice evidence using the Add Evidence Item functionality and explored its file structure.

### 3. Keyword Searching
Explored FTK Imager's Find dialog and text-search options to understand how investigators locate relevant information within evidence.

### 4. File Exports and Hash Review
Explored file and hash-list export functionality and reviewed MD5 and SHA-1 fields associated with files in the training evidence.

### 5. Hexadecimal Analysis
Inspected hexadecimal data and its ASCII representation to better understand file contents at the byte level.

## Skills Demonstrated
- Navigating digital forensic evidence with FTK Imager
- Exploring file structures and evidence contents
- Using keyword-search functionality
- Reviewing exported hash-list data
- Interpreting hexadecimal and ASCII representations
- Documenting forensic workflows with screenshots
